## 🔽 Download Process (Technical Flow)

###  **When User Clicks "Download Backend"**

```
Frontend (React)
     ↓
Sends POST request to: http://localhost:5000/api/download/generate
     ↓
Backend receives configuration object
     ↓
Backend generates custom files:
  - package.json (with selected dependencies)
  - .env (with user's SMTP settings)
  - src/server.js
  - src/routes/ (auth, admin)
  - src/controllers/
  - src/middleware/
  - src/database/init.js
  - README.md (custom instructions)
     ↓
Backend creates ZIP file
     ↓
ZIP file downloaded to user's computer
     ↓
User extracts ZIP
     ↓
User runs: npm install && npm start
     ↓
✅ Custom authentication microservice is running!
```

## 💻 How to Use the Downloaded Backend

### **After Download:**

1. **Extract the ZIP file**
   ```powershell
   # Extract to a folder like:
   C:\myproject\griffion-backend\
   ```

2. **Open in VS Code**
   ```powershell
   cd C:\myproject\griffion-backend
   code .
   ```

3. **Install Dependencies**
   ```powershell
   npm install
   ```
   This installs:
   - Express
   - JWT libraries
   - Database drivers (SQLite/PostgreSQL/MongoDB)
   - Email libraries (if password recovery enabled)
   - Security packages

4. **Review .env File**
   ```env
   # Already configured with your settings!
   PORT=5000
   DB_TYPE=sqlite
   JWT_SECRET=<auto-generated>
   SMTP_HOST=smtp.gmail.com  # Your settings
   SMTP_USER=your-email@example.com
   # ... etc
   ```

5. **Start the Server**
   ```powershell
   npm start
   ```

6. **Test Your API**
   ```powershell
   # Server is now running on http://localhost:5000
   
   # Test registration:
   curl -X POST http://localhost:5000/api/auth/register `
     -H "Content-Type: application/json" `
     -d '{"email":"test@example.com","password":"Test123!"}'
   
   # Test login:
   curl -X POST http://localhost:5000/api/auth/login `
     -H "Content-Type: application/json" `
     -d '{"email":"admin@griffion.local","password":"Admin123!"}'
   ```

## 🎨 Integration with Your Frontend

### **React Example:**
```javascript
// Login function
const login = async (email, password) => {
  const response = await fetch('http://localhost:5000/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password })
  });
  
  const data = await response.json();
  localStorage.setItem('token', data.data.accessToken);
  return data;
};

// Protected API call
const getProfile = async () => {
  const token = localStorage.getItem('token');
  const response = await fetch('http://localhost:5000/api/auth/me', {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  return response.json();
};
```

## 🆘 Troubleshooting

### **"Cannot find module 'express'"**
```powershell
# Run npm install in the backend folder
npm install
```

### **"Database connection failed"**
- Check connection string in .env
- Ensure database server is running
- For SQLite: folder `data/` will be auto-created

### **"SMTP connection failed"**
- Verify SMTP credentials in .env
- For Gmail: enable "Less secure apps" or use App Password
- Test mode will still work without SMTP

### **"Port 5000 already in use"**
```powershell
# Change PORT in .env file
PORT=3001
```
